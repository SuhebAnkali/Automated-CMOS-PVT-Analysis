# Automated CMOS Characterization and PVT Analysis

**Technologies:** Python | Ngspice | NumPy | Pandas | Matplotlib | Linux

## Overview
This repository explores an automated simulation framework for CMOS circuit characterization across Process, Voltage and Temperature (PVT) conditions.

The objective is to analyze how variations in manufacturing process, supply voltage and operating temperature influence CMOS circuit performance.

## Objectives
- Automate SPICE simulations using Python.
- Perform PVT corner analysis.
- Extract timing and power parameters.
- Compare circuit performance under different operating conditions.
- Generate simulation reports and performance graphs.

## Key Features
- Python-based simulation automation.
- Ngspice integration.
- Process corner analysis (TT, FF and SS).
- Supply voltage variation analysis.
- Temperature variation analysis.
- CSV-based simulation reporting.
- Graphical performance comparison.

## Characterization Parameters
- Propagation Delay
- Rise Time and Fall Time
- Dynamic Power Consumption
- Static Power Consumption
- Leakage Current
- PVT Performance Variation

## Expected Workflow
1. Configure circuit and simulation parameters.
2. Define process, voltage and temperature conditions.
3. Execute Ngspice simulations.
4. Extract timing and power measurements.
5. Process simulation data using Python.
6. Generate CSV reports and performance graphs.
